# C语言学习笔记

## 关键字

### static 关键字

修饰局部变量：

- 生命周期：从「仅在函数调用期间存在」变为「程序运行期间一直存在」（只初始化一次）
- 作用域：仍然只在所在函数 / 代码块内可见（不会暴露到外部）
- 作用：使局部变量具有静态存储期，即在函数调用结束后仍然存在，并且在下一次调用该函数时继续使用之前的值

例如，在STM32程序中的while循环中初始化一个static变量：serial_feedback_tick，用于定时打印串口反馈信息：

```c
while (1)
{
    static uint32_t serial_debug_tick = 0;
    if ((HAL_GetTick() - serial_debug_tick) >= 100) // 每100ms打印一次调试信息
    {
      serial_debug_tick = HAL_GetTick();
      Serial_Debug_Feedback();
    }
}
```

修饰全局变量：

- 生命周期：从「程序运行期间一直存在」变为「仅在定义它的文件内存在」
- 作用域：从「整个程序内可见」变为「仅在定义它的文件内可见」
- 作用：限制全局变量的可见性，使其只能在定义它的文件内被访问，无法被其他文件访问

修饰函数：

- 生命周期：从「程序运行期间一直存在」变为「仅在定义它的文件内存在」
- 作用域：从「整个程序内可见」变为「仅在定义它的文件内可见」
- 作用：限制函数的可见性，使其只能在定义它的文件内被调用，无法被其他文件访问

### extern 关键字

用于声明在其他文件中定义的全局变量或函数，使得当前文件可以访问这些变量或函数

例如，在头文件中声明一个已经在头文件对应的源文件中定义的全局变量，然后在其他源文件中包含这个头文件，就可以访问这个全局变量

### volatile 关键字

volatile adj. 易变的

用于声明一个可能随时被修改的变量，告诉编译器不要对该变量进行优化，每次使用时都从内存中读取其最新值
> 编译器优化是指编译器在生成机器代码时对源代码进行的一系列优化处理，以提高程序的性能和效率，例如编译器可能会将一个变量的值缓存到寄存器中，而不是每次都从内存中读取最新值，这就可能导致其他线程修改该变量的值后，当前线程无法及时获取到最新的值，从而引发错误

一般来说，volatile 关键字适用于以下变量：

- 在中断中修改或访问的变量
- 多任务（线程）共享的变量
- 硬件寄存器变量

### const 关键字

const adj. 常量的，不变的

用于声明一个变量的值不可修改，告诉编译器在编译时检查对该变量的修改操作，如果有修改操作会产生编译错误

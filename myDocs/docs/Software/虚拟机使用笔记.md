# 虚拟机使用笔记

以VMWare，Ubuntu为例

## 共享文件夹

1. 在虚拟机设置中添加共享文件夹
2. `sudo mount -t fuse.vmhgfs-fuse .host:/ /mnt/hgfs -o allow_other`
   - `/mnt/hgfs/` 是挂载点，我们也可以修改为其它挂载点
   - `-o allow_other` 表示普通用户也能访问共享目录。
3. `ls /mnt/hgfs` 查看共享文件夹
4. 添加永久挂载点：`echo '.host:/ /mnt/hgfs fuse.vmhgfs-fuse allow_other,defaults 0 0' | sudo tee -a /etc/fstab`
5. 重启后生效

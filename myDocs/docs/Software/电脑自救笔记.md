# 电脑自救笔记

## 更新Intel驱动后电脑黑屏

解决方法：回滚到之前的驱动版本

1. 长按电源键关机，再按电源键重启
2. 在开机图标出现时狂按delete键，进入恢复菜单，选择`查看高级选项`
3. 选择`疑难解答选项`
4. 在`高级选项`菜单中选择`启动设置`
5. 按`5`启用带网络连接的安全模式或`4`启用安全模式
6. 进入桌面，打开设置
7. 选择`系统`->`系统信息`->`设备管理器`
8. 选择`显示适配器` -> `Intel(R) UHD Graphics`，双击打开
9. 选择`回退驱动程序`或`卸载设备`（重启后系统会自动下载，没试过😐）
10. 重启电脑，解决😎

教训：

- 适合自己的才是最好的😂，最新驱动可能不适合你的电脑，要更新驱动应找电脑厂商的官网根据自己的情况下载适合自己的驱动
- 对于华硕电脑，可以打开MyASUS程序，选择系统更新，更新驱动

## 调整图纸大小

- 单击【选项】——>选择并单击【电路图属性】
- 在弹出的【电路图属性】选项卡，选择并单击【工作区】，单击【电路图页面大小】的下拉菜单并选择【A0】，单击【确定】按钮

## BUG笔记

### 访问数据库时发生错误

打开Multisim时，弹出错误提示：

```txt
访问数据库时发生错误
主数据库 无法访问。使用 主数据库 的功能将不可用。
```

尝试：

参考 BV1JPyHBKEvH 视频评论区的方法：打开一个Multisim窗口，不理会第一个窗口的错误，打开第二个窗口，可以正常使用。暂时先这样

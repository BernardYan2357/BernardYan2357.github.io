# 几种配置文件

## yaml文件

YAML 是 "YAML Ain't a Markup Language"（YAML 不是一种标记语言）的递归缩写，是一种强调可读性的数据序列化格式。YAML 的配置文件后缀为 .yml 或 .yaml。

其基本语法规则包括：
- 使用缩进表示层级关系，通常使用空格（缩进的空格数不重要，只要相同层级的元素左对齐即可），不允许使用制表符（Tab）
- 大小写敏感
- 使用 `#` 进行注释，注释内容从 `#` 开始直到行尾
- 键值对使用冒号 `:` 分隔，冒号后面应有一个空格
- 列表项使用短横线 `-` 开头，后面跟一个空格

YAML 支持以下几种数据类型：

- 对象：键值对的集合，又称为映射（mapping）/ 哈希（hashes） / 字典（dictionary）
- 数组：一组按次序排列的值，又称为序列（sequence） / 列表（list）
- 纯量（scalars）：单个的、不可再分的值

示例：
```yaml
languages:
  - Ruby
  - Perl
  - Python 
websites:
  YAML: yaml.org 
  Ruby: ruby-lang.org 
  Python: python.org 
  Perl: use.perl.org
```

## json文件

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式，易于人阅读和编写，同时也易于机器解析和生成。JSON 使用键值对的形式来表示数据结构，支持数组和嵌套对象。

JSON 的基本语法规则包括：
- 数据在名称/值对中
- 数据由逗号分隔
- 花括号保存对象
- 方括号保存数组
- 字符串必须使用双引号

json文件示例：

```json
{
  "name": "John",
  "age": 30,
  "isStudent": false,
  "courses": ["Math", "Science"],
  "address": {
    "street": "123 Main St",
    "city": "New York"
  }
}
```

## xml文件

XML 指可扩展标记语言（eXtensible Markup Language）。被设计用来传输和存储数据，不用于表现和展示数据，HTML 则用来表现数据。两者语法上有很多相似之处

使用<?xml version="1.0"?>声明 XML 版本，通常放在 XML 文件的第一行

XML 由标记（Tag）和属性（Attribute）组成，标记用来定义数据的结构，属性用来提供额外的信息。

一个 XML 标记的基本格式如下：

```xml
<标记名称 属性名1="属性值1" 属性名2="属性值2">内容</标记名称>
```

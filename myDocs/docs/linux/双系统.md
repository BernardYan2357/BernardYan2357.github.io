# 双系统

## 双系统的安装

references:

- [Ubuntu/Windows双系统安装巨详细——全面解决各种问题（疑难杂症），有手就行](https://blog.csdn.net/NeoZng/article/details/122779035)

以在 windows 系统上安装 ubuntu-22.04为例，安装步骤如下：

1. 将系统盘其一进行卷压缩，腾出 100 GB 的未分配空间
2. 制作系统启动盘
    - 下载 ubuntu-22.04 的 iso 镜像文件，并使用 Rufus 工具将其写入U盘，制作成启动盘
3. 在系统设置中关闭快速启动
    - 进入控制面板 -> 电源选项 -> 选择电源按钮的功能 -> 更改当前不可用的设置 -> 取消勾选启用快速启动
4. 在 BIOS 中关闭安全启动
5. 重启电脑，进入 BIOS 设置，将 U 盘设置为第一启动项
6. 进入 Ubuntu 安装界面，选择安装 Ubuntu
   - 在安装类型界面选择“其他选项”，手动分区
   - 选择之前压缩出的未分配空间，创建新的分区表

# 图形

在计算机图形学中，图形是指通过计算机生成的视觉内容。它可以包括二维图像、三维模型、动画等

## 图形协议

图形协议是指用于在计算机系统中传输图形数据的协议。这些协议定义了如何表示、传输和处理图形信息，以便在不同的设备和应用程序之间进行通信。常见的图形协议包括：

- OpenGL：一种跨平台的图形API，用于渲染2D和3D图形
- DirectX：微软开发的图形API，主要用于Windows平台上的游戏和多媒体应用
- Vulkan：一种低级别的图形API，提供更高的性能和更好的控制，适用于高性能图形应用
- WebGL：一种基于OpenGL ES的图形API，用于在Web浏览器中渲染3D图形
- X11：一种用于Unix和类Unix系统的图形协议，提供了基本的图形功能和窗口管理

### 查看当前系统使用的图形协议

```bash
echo $XDG_SESSION_TYPE
```

### 更改系统图形协议

```bash
sudo nano /etc/gdm3/custom.conf
# 取消对 WaylandEnable=false 的注释
sudo systemctl restart gdm3 # 重启图形界面
```

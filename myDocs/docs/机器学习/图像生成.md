# 图像生成

图像生成的基本原理

这个领域是 文生图 设定1：数学设定 任何图片的像素本质上是nxn的一个大矩阵 设定2：空间足够大 高维空间能表示一切（事实上就是同样1024*1024的图片是海量的） 设定3：空间容纳了所有概念 n²足够大，容纳一切你需要的概念 设定4：每个概念（向量）都在空间里 图片就是大向量 设定5：相似概念（向量）的距离会很接近 泛指概念在空间中是一块区域 猫和狗都是动物 所以含猫含狗的照片会接近 设定6：支持概念（向量）加减法 国王-男+女＝女王 我们训练模型就是让模型生成这些向量 输入语句，模型一般会分词： 草地 猫 橘 坐 根据这些，经过模型生成大向量（就是图片）

### CLIP

References: 
- [Introduction to CLIP | OpenCV](https://opencv.org/clip/)
- [可视化直观地理解CLIP模型](https://www.bilibili.com/video/BV1JgMK6uEQA)

在学习 Diffusion Model 时我们知道模型以文本提示词和噪点图片为输入，生成图片，也就是说模型同时负责理解提示词的视觉含义和根据视觉含义对噪点图去噪的两项任务。能做是能做，但是相比于直接接收视觉含义进行去噪效率要低。CLIP 模型充当了提示词与模型之间的中间人，将提示词的视觉含义提取出来送给 Diffusion Model

CLIP, which stands for **Contrastive Language-Image Pre-training** (对抗式语言-图像预训练模型), is a model that learns the relationship between visual data (images) and textual data (language). To achieve this, it was trained on a **400 million image-text pairs** scraped from the internet. This immense(巨大的) scale is what gives it such a *vast and nuanced* (宏大而细腻) understanding of concepts

CLIP 的训练方式：

![[CLIP.png|585]]

- Text Encoder：文本编码器采用 Transformer 架构，接收一段文本，并将其转化为特定维度的特征向量，作为对文本含义的总结
- Image Encoder：图像编码器采用 ViT 架构，负责处理图像，将其转换为与文本向量维度一致的特征向量
- 在训练 CLIP 的两个 Encoder 时，一次投入多组文本图片对，将多组向量放在上图的表格中比较
	- 对角线单元格上的图片向量和文本向量要尽可能靠近，因为它们的原文和原图是一对
	- 其它单元格上的图片向量和文本向量要尽可能远离，因为它们的原文和原图不匹配
	- 这种距离上的远近可以用余弦相似度来衡量，特征向量首先被L2归一化，然后有：$cos(\theta) = \frac{a\cdot b}{||a||\cdot||b||} = a\cdot b$
	- 将差异回传到之前的网络进行训练

由于 CLIP 独特的训练机制，我们在得到文本编码器同时还得到了图像编码器。利用图像编码器，我们可以将参考图也转换为特征向量传入 Diffusion Model，从而实现图生图的功能

### VGG

VGG 是一种卷积神经网络，由牛津大学的 Visual Geometry Group 提出：[Very Deep Convolutional Networks for Large-Scale Image Recognition](https://www.robots.ox.ac.uk/~vgg/publications/2015/Simonyan15/simonyan15.pdf)，最初用于图像分类。它主要通过堆叠 $3\times3$ 卷积、ReLU 和最大池化层，逐层提取图像特征

常见版本：
- **VGG-16**：13 个卷积层 + 3 个全连接层
- **VGG-19**：16 个卷积层 + 3 个全连接层

#### 作为特征提取器

分类网络需要先提取图像特征，再根据特征判断类别。用 VGG 提取特征时，通常加载在 ImageNet 上预训练的权重，使用部分卷积层的输出，无需运行最后的分类层

不同深度的特征可以粗略理解为：

| 网络位置 | 通常反映的信息 |
|------|------|
| 浅层 | 边缘、颜色变化、局部纹理 |
| 中层 | 纹理组合、局部形状、物体部件 |
| 深层 | 更大范围的结构和与类别有关的信息 |

这些特征由训练学得，各层的作用没有严格分界，也不能把每个通道固定解释为某个物体部件

记第 $l$ 层的输出为：

$$
\phi_l(x)\in\mathbb{R}^{C_l\times H_l\times W_l}
$$

其中 $x$ 是输入图像，$C_l$ 是通道数，$H_l,W_l$ 是特征图的高和宽。**特征图仍保留空间位置**，每个位置对应一组特征响应。论文中的 relu3_3 通常表示第 3 个卷积块中第 3 个卷积层经过 ReLU 后的输出

#### 在图像生成中的作用：感知损失

图像生成、风格迁移和超分辨率任务中，常用 VGG 比较生成图像与目标图像的特征。设生成图像为 $\hat y=G_\theta(x)$，目标图像为 $y$，一种常见的感知损失为：

$$
\mathcal L_{\mathrm{perceptual}}
=
\sum_{l\in\mathcal S}
\frac{\lambda_l}{C_lH_lW_l}
\left\|\phi_l(\hat y)-\phi_l(y)\right\|_2^2
$$

- $\mathcal S$：选取的 VGG 层
- $\lambda_l$：各层的损失权重
- 两张图像经过同一个 VGG，比较对应层的特征差异；具体论文也可能使用 $L_1$ 距离

像素损失直接比较对应像素的数值；感知损失比较网络提取的视觉特征，因此能够从不同层次约束生成图像的细节与内容。选层会影响约束效果，特征接近也不保证像素或几何结构完全一致

经典风格迁移还会比较 VGG 特征的 **Gram 矩阵**，用通道之间的相关性描述纹理和风格。直接比较特征与比较 Gram 矩阵是两种不同的损失构造

### Diffusion Model

References: [可视化直观地理解Diffusion(扩散模型)](https://www.bilibili.com/video/BV1eiNTzzE4L)

**扩散模型（Diffusion Model）** 是一类**生成式模型**，通过模拟数据逐步被噪声“破坏”的过程，然后学习逆向过程从纯噪声中逐步恢复出真实数据。它在图像、音频、视频生成领域取得了巨大成功

#### 核心思想

扩散模型包含两个过程：

1. **前向扩散过程（加噪）**：对原始数据 $x_0$ 逐步添加高斯噪声，经过 $T$ 步后，数据几乎完全变成纯噪声 $x_T \sim \mathcal{N}(0, I)$。这是一个固定的马尔可夫链，无需训练
2. **反向去噪过程（去噪）**：训练一个神经网络（通常是 UNet）来预测每一步添加的噪声，从而从 $x_T$ 逐步还原出 $x_0$

#### 关键特点

- **生成质量高**：相比 GAN，扩散模型更稳定，不易模式崩溃，样本多样性更好
- **迭代采样**：生成一张图像需要多次（通常 20~100 步）去噪步骤，速度较慢，但可通过更快的采样器（DDIM、DPM++）加速
- **条件生成**：通过输入条件（如文本、类别标签、图像），可控制生成内容，这是 Stable Diffusion、DALL·E 等模型的基础

#### Stable Diffusion

**Stable Diffusion** 是一种基于**扩散模型**（Diffusion Model）的文本生成图像（Text-to-Image）模型，由 Stability AI 与 Runway 等机构在 2022 年开源发布。它能够根据自然语言描述生成高质量的图像，是当前 AI 绘画领域最流行的基础模型之一

##### 核心原理

Stable Diffusion 采用**潜在扩散模型**（Latent Diffusion Model, LDM），主要分三个阶段：

1. **编码**：将图像通过 VAE（变分自编码器）压缩到低维潜在空间（Latent Space），减少计算开销
2. **扩散过程**：在潜在空间中，向图像特征逐步添加噪声，再训练一个 UNet 去预测并去除噪声
3. **解码**：将去噪后的潜在表示通过 VAE 解码器还原为像素图像

其中**文本引导**通过 CLIP 文本编码器将提示词（Prompt）编码为条件向量，控制 UNet 的生成方向

##### 关键组件

| 组件 | 作用 |
|------|------|
| VAE 编码器/解码器 | 在像素空间与低维潜在空间之间转换 |
| UNet（主干网络） | 在潜在空间中进行降噪预测 |
| CLIP 文本编码器 | 将文本提示转换为条件向量 |
| 采样器（Scheduler） | 控制去噪步数与策略（如 DDIM、DPM++、Euler） |

##### 常见应用场景

- **文生图**：根据自然语言描述生成图像（如“一只穿着宇航服的猫”）
- **图生图**：以一张图像为基础，结合文本进行风格转换或局部修改
- **ControlNet**：通过额外条件（如姿态、深度、边缘图）精确控制生成构图
- **LoRA 微调**：训练小型 LoRA 模型，定制特定人物、画风或物体

## 图像风格迁移

Image style transfer 的主要任务是两个：一是将图像风格迁移到目标图像，其次是保留目标图像的画面结构

按训练数据是否配对，可分为以下两类：

1. Paired Training
   以 Pix2Pix 为代表的配对训练方法表现优异，尤其适用于需要严格保持原始结构的任务。配对数据中像素级的对应关系能够提供明确的监督信号，帮助模型在风格化过程中保留高频细节和语义信息。但是高质量的配对数据集非常稀缺

2. Unpaired Training
   为缓解配对数据不足的问题，CycleGAN 引入了非配对图像转换框架，无需使用严格对齐的图像对进行训练。不过，这类方法容易产生几何伪影和结构畸变，难以保留高保真风格化所需的精细结构与细节

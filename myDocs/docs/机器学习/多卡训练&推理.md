# 多卡训练&推理

References: [Reduce memory usage using multiple gpus · Hugging Face](https://huggingface.co/docs/diffusers/optimization/memory#multiple-gpus)

在训练较大的模型时，如果模型大小大于单张显卡的显存大小，将无法训练，这时候我们就需要利用多张显卡一起训练。此外，如果要加速训练的进程，也可以使用多卡训练，推理同理

## 数据并行

最简单的方法，将数据集分为多部分，在多张卡上运行训练脚本，分别读取不同的部分

## Sharded checkpoints

> Checkpoint 是用于描述在每次训练后保存的模型参数（权重）的术语，正如它最常见的含义：检查点，我们可以加载 Checkpoint 继续训练或进行推理

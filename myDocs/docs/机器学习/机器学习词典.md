# 机器学习词典

## Embedding

Embedding，嵌入，也叫向量表示。把词、图片、商品等离散对象映射成一个低维向量，使得这些数据可以输入模型。对于同属于一个语义向量空间的 Embeddings，它们的向量距离也能反映语义距离。比如 "猫" 和 "狗" 的向量距离近，"猫" 和 "汽车" 的距离远

常见用法：
- **词向量**：Word2Vec、GloVe，把词表示成向量，是早期 NLP 的基础
- **语言模型 Embedding**：大模型先把 token 转成向量再处理，输出也能取一段文本的整体向量
- **多模态 Embedding**：CLIP 把图片和文本映射到同一向量空间，图和文可以直接比相似度
- **检索 / RAG**：把文档切块转成向量存进向量数据库，用问题向量找最相似的内容，再喂给大模型

## Align

Align，对齐，让两个原本不一致的东西产生对应关系或趋于一致

常见语境：
- **表示学习中的对齐**：让语义相关的东西在向量空间里靠得更近，[[机器学习词典#Embedding]] 的训练就是在做这种对齐。CLIP 把图片和文本对齐到同一空间，让图和文能直接比相似度
- **多模态对齐**：让不同模态（文本、图像、音频）的表征建立对应。回答"这张图对应哪段文字描述"，本质就是跨模态对齐
- **对齐（Alignment，大模型语境）**：让模型的行为符合人类意图和价值观，即 AI Alignment。[[机器学习词典#Foundation models]] 预训练完之后，用 SFT、RLHF、DPO 等方式做对齐，让模型有用、诚实、无害（Helpful, Honest, Harmless）
- **序列对齐**：两段序列按时间或位置对应起来。语音识别里把音频帧和文字标签对齐，机器翻译里把源句和目标句的词对齐
- **特征对齐 / 分布对齐**：让源域和目标域的特征分布尽量一致，是域适应（Domain Adaptation）的核心思路

## Regularization

Regularization，正则化，区别于 Normalization，归一化

在机器学习语境中，Regularization 指在训练模型时额外加一些约束或信息，防止模型过拟合，提高模型泛化能力

常见正则化方式：
- **L2 正则**：在损失函数里加权重平方惩罚，让权重别太大
- **L1 正则**：加权重绝对值惩罚，让模型更稀疏
- **Dropout**：训练时随机丢掉一些神经元，防止过度依赖某些特征
- **数据增强**：把图片旋转、裁剪、变色，让模型见更多变化
- **早停**：在验证集上的评分不再提升就停止训练
- **标签平滑**：不要把答案绝对化成 0/1，降低过度自信
- **合成数据**：人为造一些额外样本参与训练

## Parameter Count

Parameter Count，参数量。指模型中可学习参数的总数，主要包括权重和偏置。训练时，模型通过调整这些参数学习数据中的规律

常见说法：
- **M / B**：M 表示百万（Million），B 表示十亿（Billion）。7B 约为 70 亿参数，70B 约为 700 亿参数
  - 例句：这个模型有 7B 参数，也就是约 70 亿个可学习参数
- **参数量与性能**：在架构和训练条件相近时，更多参数通常能提供更强的表达能力；实际效果也取决于训练数据、方法和具体任务
  - 例句：这个 7B 模型在当前任务上比另一个 13B 模型表现更好
- **参数量与显存**：存储模型权重所需的空间约为参数量乘以每个参数的字节数。7B 模型使用 FP16 时，权重约占 14 GB；运行时还需要 KV Cache 等额外空间
  - 例句：7B 模型的 FP16 权重约占 14 GB，推理显存还要留出余量
- **总参数 / 激活参数**：MoE（混合专家）模型每次处理一个 token 时只调用部分专家，因此总参数量可以很大，而激活参数量较小
  - 例句：这个 MoE 模型总参数为 30B，每个 token 激活约 3B 参数
- **量化与参数量**：量化降低每个参数的存储精度，通常不改变参数个数
  - 例句：7B 模型量化到 4-bit 后，参数量仍是 7B，但权重占用更小

## Benchmark

**Benchmark**, n. 基准。在大语言模型领域中，Benchmark（基准测试）指代用于评估和比较大语言模型性能的一系列标准化任务、数据集和评价指标

## Baseline

Baseline，基准线，一个参考模型，用于比较和评估自身模型的性能

## SOTA

**SOTA** 是 State-of-the-Art 的缩写，中文常译为“当前最先进水平”或“最高水准”。在机器学习领域，SOTA 通常指在某个任务或数据集上性能最好的模型、方法或结果，是衡量算法优劣的常用基准（例如：“该模型在 ImageNet 上达到了 SOTA 性能”）

## Ablation Study

References:  [一文搞懂什么是ablation study (消融实验）](https://zhuanlan.zhihu.com/p/644502891)

Ablation study，消融实验。消融实验听起来高级，说白了就是控制变量法

狭义上的消融实验：切除神经网络某些部分，对比切除前后神经网络的性能变化，研究这个部分对于系统整体的影响

## Foundation models

Foundation models，基座模型。在海量数据上预训练出来的大模型，通用性强，微调或加提示就能适配各种下游任务，不用每个任务从头训

常见的 Vision Foundation Model：
- **[[图像生成#CLIP]]**：图文对比学习，让图像和文本对齐，零样本分类能力强，多模态模型的视觉编码器首选
- **DINO / DINOv2**：自监督学习，不用人工标签就能学出好特征，检测、分割都好用
- **SAM / SAM2**：Segment Anything，点一下或给个提示就能分割任意物体，SAM2 进一步支持视频的图像分割

## Activation Function

Activation Function，激活函数。激活函数一定不能是线性函数，因为使用线性函数作为激活函数的神经网络始终能找到一个线性函数与其效果（输出）相同，这样就丧失了神经网络的非线性表达能力

有以下这些：

- **Step function**：$f(x)=\begin{cases}1,&x\ge 0\\0,&x<0\end{cases}$，输入达到阈值时输出 1，否则输出 0
- **Sigmoid function**：$\sigma(x)=\dfrac{1}{1+e^{-x}}$，sigmoid 函数的平滑性对神经网络的学习具有重要意义
- **ReLU**：$\operatorname{ReLU}(x)=\max(0,x)$，负数输出 0，正数保持不变，ReLU 相较于 Sigmoid 计算简单，同时 ReLU 会把负输入变成 0，让一部分神经元在当前输入下不激活，这有时有助于学习更简洁的表示。在深层网络的反向传播中，梯度经过多层相乘，容易变得很小，而 Sigmoid 在输入很大或很小时会饱和，梯度接近 0，前面几层就学得慢。ReLU 梯度传递通常更顺畅
- **LeakyReLU**：$\operatorname{LeakyReLU}(x)=\begin{cases}x,&x\ge 0\\\alpha x,&x<0\end{cases}$，其中 $\alpha$ 是较小的正数（如 $0.01$）。使用 ReLU 时，输入为负会使输出和梯度都为 0，某些神经元可能在训练过程中“死掉”，后面很难再更新。这个问题通常叫 **dying ReLU**，Leaky ReLU 给负数区域留了一点梯度，在训练时不容易丧失梯度。常用于 GAN

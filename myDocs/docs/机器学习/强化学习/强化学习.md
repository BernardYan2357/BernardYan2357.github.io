# 强化学习

## 训练方法

- RLHF (Reinforcement Learning with Human Feedback)，代表模型：GPT-3
- RLVR (Reinforcement Learning with Verifiable Rewards)，代表模型：DeepSeek-R1
- RLCD (Reinforcement Learning for Calibrated Decisions，校准决策强化学习)，代表模型：Jev

AI 在编码和数学领域率先取得突破，很大原因是编码和数学都有明确的评价指标，模型能够在不断训练中拟合；而在其它领域（文学、艺术等）中评价指标往往是模糊的，主观的

# 机械臂

## 舵机机械臂的校准

校准，让机械臂的实际动作与预期（如 moveit2）一致

### SO-ARM101

SO-ARM101 采用 STS3215 12V 舵机作为驱动器。[[舵机#STS3215]] 为串行总线舵机，可以反馈舵机角度（Tick）

校准步骤：

- 编写实时读舵机角度脚本，读取各舵机当前角度
- 启动 display.launch，显示 URDF 和 robot_state_publisher_gui
- 依次将各机械臂关节摆放到与 URDF 中定义的零位一致的位置，记录它们的 Tick 值
- 依次将各机械臂关节旋转至极限位置（应预留一定空间），记录 Max 和 Min 时的 Tick 值（如果关节的活动范围是关于零位对称的，可以根据对称原则修正极限 Tick 值）
- 在旋转各关节时，观察 Tick 递增的方向是否与 URDF 中弧度递增的方向一致。如果不一致则取反 URDF 中对应关节的 `<axis>`，因为舵机的转向无法修改
- $Offset_{max} = Tick_{max} -2048$，$Offset_{min} = 2048 - Tick_{min}$，将 $Offset$ 通过 $Offset_{rad} = \frac{Offset_{tick}}{4096} \times 2 \pi$ 换算为弧度，填入 URDF 的 `<limit>`，这是用真实限位重置 URDF 限位
- 让实际零位与 URDF 零位对齐：利用 STS3215 自带的 EEPROM（保存舵机 ID、零位偏移、角度限制等参数），${Present_Position} = {Actual_Position} - {Homing_Offset}$，其中 $Present_Position$ 设为2048，${Actual_Position}$ 为之前记录的零位 Tick，得到 `homing_offset`，写入 feetech_ros2_driver 要求的 joints_config.yaml 中，`homing_offset`会在驱动初始化时写入舵机
- 基于修改的 URDF 重新生成 moveit_config

### PWM 舵机机械臂

PWM 舵机机械臂没有角度反馈，一般都会设置“机械臂竖直、关节齐平、夹爪半张开”作为 URDF 零位，在控制程序上也会设置 PWM=1500 为零位时的 PWM 值

## 常见机械臂

### SO-ARM101

References:

- [主页 | GitHub](https://github.com/TheRobotStudio/SO-ARM100)
- [入门教程 | Seeed Studio](https://wiki.seeedstudio.com/cn/lerobot_so100m_new/)
- [SO-ARM with ROS2 | GitHub](https://github.com/JafarAbdi/ros2_so_arm)

SO-ARM 系列机械臂是一套开源的5自由度舵机机械臂，包含主臂和从臂。SO-ARM101 是 SO-ARM100 的升级版本，优化了走线方案，简化了拆卸流程，其从臂舵机换为12V舵机

### UR5

UR5 是 Universal Robots 公司生产的一款6自由度协作机器人，具备高可靠性与易用性，广泛应用于工业自动化领域

### Panda

Panda 是由 Franka Robotics 公司生产的一款7自由度机械臂，具有高精度和灵活性。其每个关节都具备高精度力传感器，触觉极灵敏；支持1000Hz高频代码控制，是AI大模型训练的首选机械臂

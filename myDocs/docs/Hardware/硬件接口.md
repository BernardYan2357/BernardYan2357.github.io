# 硬件接口

## DC

DC（Direct Current）接口是电源输入接口，通常用于连接电源适配器为设备供电

DC接口的型号通常以直径和内径来区分，常见的型号有：

- DC 5.5mm x 2.1mm：5521
- DC 5.5mm x 2.5mm：5525

5525 因内径更大、中心针更粗，接触面积更大、接触电阻更低，因此能承载更大的电流（5~10A）且发热更小。两种接口不兼容，选型时需根据设备功耗匹配

## HDMI

HDMI（High-Definition Multimedia Interface）接口是一种数字视频和音频接口，常用于连接显示器、电视和其他多媒体设备

HDMI接口的常见类型有：

- Type A：标准 HDMI接口，尺寸：13.98mm x 4.45mm，19针，常用于电视、显示器和一些电脑设备
- Type C：Mini HDMI接口，尺寸：10.42mm x 2.42mm，19针，常用于平板电脑、数码相机和一些小型设备
- Type D：Micro HDMI接口，尺寸：6.42mm x 2.8mm，19针，通常用于智能手机和一些小型设备

# 电脑BUG笔记

## 更新Intel驱动后电脑黑屏

解决方法：回滚到之前的驱动版本

1. 长按电源键关机，再按电源键重启
2. 在开机图标出现时狂按`delete`键，进入恢复菜单，选择`查看高级选项`
3. 选择`疑难解答选项`
4. 在`高级选项`菜单中选择`启动设置`
5. 按`5`启用带网络连接的安全模式或`4`启用安全模式
6. 进入桌面，打开设置
7. 选择`系统`->`系统信息`->`设备管理器`
8. 选择`显示适配器` -> `Intel(R) UHD Graphics`，双击打开
9. 选择`回退驱动程序`
10. 重启电脑，解决😎

教训：

- 适合自己的才是最好的，最新驱动可能不适合你的电脑，要更新驱动应找电脑厂商的官网根据自己的情况下载适合自己的驱动
- 对于华硕电脑，可以打开MyASUS程序，选择系统更新，更新驱动

## 电脑开机后内存占用60%左右

references:

- [win10一开机，内存占用过高，达到60%，是什么原因](https://www.zhihu.com/question/39716538)
- [高达 7GB 的 Windows 非分页缓存池内存泄露解决方法](https://blog.csdn.net/qq_42683499/article/details/151766747)
- [Win11 使用WSL2的时候会产生非分页内存泄漏](https://linux.do/t/topic/1302617/33)

电脑开机后内存占用60%左右，很显然不正常

尝试：

- 打开任务管理器的`启动应用`，禁用了不必要的开机启动项，减少开机时的资源占用
- 按 Win+R 输入 `services.msc`，禁用了：
  - `Windows Search`：不常用本地搜索的话，可以禁用，减少索引占用，后面还是开启了，毕竟有时候需要用到
  - `Connected User Experiences and Telemetry`：遥测服务，可禁用减少后台消耗

> 以上两步都没有明显改善内存占用

- 使用 RAMMap 工具查看内存占用情况，发现 `Nonpaged Pool`（非分页缓冲池）占用了惊人的 `13.25GB`，说明有某个驱动或系统组件在泄漏内存，正常应该只有几百 MB。查看任务管理器的`性能`->`内存`，也可以发现非分页池占用异常高
- 尝试重启电脑，发现 `Nonpaged Pool` 占用缩小至 1 GB 左右，暂时解决了问题
- 未完待续...（需要观察一段时间，看看是否再次出现内存泄漏）

## win键失灵

references:

- [windows键/win键摁了没反应/win键被禁用怎么办](https://zhuanlan.zhihu.com/p/536966730)

在网上搜索得到解决方案：先按住键盘上的FN键不放，然后按一下win键，即可恢复正常

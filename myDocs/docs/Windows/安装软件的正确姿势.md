# 安装软件的正确姿势

Windows传统的软件下载和安装方式比较分散，建议尽量使用包管理器来安装、升级和卸载软件，这样更方便管理

Windows目前有以下几种软件包管理器：

- winget：微软官方的软件包管理器，适合大多数常见软件
- Scoop：第三方软件包管理器，偏向开发者工具和命令行工具
- Chocolatey：第三方软件包管理器，生态很大，适合脚本化批量安装

一般来说，个人电脑优先用 winget 或 Scoop 就够了；如果是脚本批量装机，再考虑 Chocolatey

## 校验安装包

如果你需要从官网下载软件安装包，建议先校验安装包的哈希值，确保下载的文件没有被篡改或损坏

大多数软件官网会提供安装包的哈希值（MD5、SHA1、SHA256等），我们需要在命令行中计算下载文件的哈希值，并与官网提供的值进行对比：

```powershell
Get-FileHash -Path <安装包路径> -Algorithm SHA256
# 判断结果是否与官网提供的哈希值一致
$hash1 = "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855"
$hash2 = "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855"
$hash1 -eq $hash2   # 返回 True 或 False
```

## 为当前用户安装？

安装软件时，通常会有一个选项让你选择是为当前用户安装，还是为所有用户安装

- 为当前用户安装的软件通常只对当前用户可见，环境变量也主要写入当前用户配置
- 为所有用户安装的软件会写入系统级位置，所有用户都可以使用

只有这几种情况才更适合选择为所有用户安装：

- 开发环境、驱动、运行库（VC++、.NET、Java 等）需要全局生效
- 某些软件只支持机器级安装，选择 user 会报错
- 你明确希望所有账号共享同一份软件

## winget

winget 常用命令：

```powershell
winget search <关键字> # 搜索软件
winget show --id <包ID> # 显示软件信息
winget install <软件名/ID> # 安装软件
    --id <包ID> -e # 安装软件，使用包ID并精确匹配
    --scope <安装范围> # 指定安装范围，user 或 machine
    --location <位置> # 指定安装位置
    --accept-package-agreements # 自动接受程序包协议
    --accept-source-agreements # 自动接受源协议
winget uninstall <软件名/ID> # 卸载软件
winget upgrade # 列出所有可升级的软件
    --id <包ID> -e # 升级指定软件，使用包ID并精确匹配
    --all # 更新所有可升级软件
winget source update # 更新源
winget list # 列出已安装的软件
	--name # 查找已安装的软件
winget export -o <文件路径> # 将已安装软件列表导出为 JSON 文件
winget import -i <文件路径> # 根据 JSON 文件批量安装软件
```

- `--location` 能否生效取决于安装程序是否支持，最好是指定到一个空文件夹，而不是“D://Apps”，路径里也不要包含空格，这样路径容易解析失败

winget 的安装位置会受到安装程序本身影响，下面是常见情况，不是绝对固定值：

- 为当前用户安装的软件：通常会落在 `%LOCALAPPDATA%\Programs` 或用户目录下的其他位置
- 为所有用户安装的软件：通常会落在 `%PROGRAMFILES%`
- 为当前用户安装的便携式软件：`%LOCALAPPDATA%\Microsoft\WinGet\Packages`
- 为所有用户安装的便携式软件：`%PROGRAMFILES%\WinGet\Packages`

你可以通过编辑 `%LOCALAPPDATA%\Microsoft\WinGet\Settings.json` 文件来修改部分默认行为，详情参考[winget Settings](https://github.com/microsoft/winget-cli/blob/master/doc/Settings.md)，例如：

```json
{
  "$schema": "https://aka.ms/winget-settings.schema.json",
  "installBehavior": {
    "defaultInstallRoot": "D:\\Apps\\"
  }
}
```

如果你想先看当前设置，可以直接运行 `winget settings`

## 正确卸载软件

在电脑上运行软件安装包时，安装程序会生成一些程序文件、后台服务和注册表项等，程序运行时的数据大部分会保存至用户目录下的`AppData`文件夹中。当你卸载程序时有时无法完全清除所有相关文件和注册表项，导致残留垃圾文件和注册表项

通过控制面板中的卸载程序界面调用软件自带的卸载程序可以解决大部分程序的卸载，然而若要更干净彻底地卸载程序，可以采用：[Geek Uninstaller](https://geekuninstaller.com/download)
> 谨慎使用Geek Uninstaller，存在过度清理注册表的风险，建议使用前备份注册表或创建系统还原点

## 在默认打开方式设置中去掉已失效/已删除的应用选项

打开注册表编辑器，定位到以下路径：
`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\FileExts\(后缀名)`
> 可以下载[Registry Workshop](https://www.torchsoft.com/en/rw_information.html)进行查找与编辑，更方便

- 删除`UserChoice`项下的`Progid`字符串值或者填上你想要的默认程序的ProgID值（可以在`HKEY_CLASSES_ROOT`中找到对应程序的ProgID值）
- 删除`OpenWithList`项下的对应程序的字符串值

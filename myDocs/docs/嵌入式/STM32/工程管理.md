# 工程管理

## 新建工程

### 新建工程步骤

- 建立工程文件夹，Keil中新建工程，选择型号
- 工程文件夹里建立Start、Library、User等文件夹，复制固件库里面的文件到工程文件夹
- 工程里对应建立Start、Library、User等同名称的分组，然后将文件夹内的文件添加到工程分组里
- 工程选项，C/C++，Include Paths内声明所有包含头文件的文件夹
- 工程选项，C/C++，Define内定义USE_STDPERIPH_DRIVER
- 工程选项，Debug，下拉列表选择对应调试器，Settings，Flash Download里勾选Reset and Run

## 工程文件管理

1. 在工程文件夹内建立Start、Library、User等文件夹，分别存放启动文件、库文件和用户代码。
2. 在工程文件夹内建立Hardware文件夹，用于存放硬件驱动代码（LED等），即启动RCC时钟，初始化GPIO，以及各种自定义函数。

### 头文件的写法

头文件的写法应当遵循以下规范：

- 头文件名应与源文件名一致。
- 头文件内容应当使用`#ifndef`、`#define`和`#endif`来防止重复包含。
  
  ```c
  #ifndef __LED_H
  #define __LED_H
    void LED_Init(void);
    void LED_On(void);
    void LED_Off(void);
  #endif
  //结尾空一行，不然会报错
  ```

## 工程导出

### 导出项目文件

使用keilkill批处理文件在打包前清除编译产生的中间文件。

### 导出HEX文件

1. 打开keil，选择工程文件，点击菜单栏中的`option for target`->`output`
2. 勾选`Create HEX file`
3. 点击`OK`
4. 编译后即可在`object`文件夹下找到对应的hex文件。

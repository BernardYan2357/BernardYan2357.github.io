# XR2206信号发生器

## 功能

- 可产生正弦波，三角波，方波
- 频率从1HZ-1MHZ变化
- 幅度可调

## 参数

- 电源电压：9-12V直流输入
- 波形：正方形，正弦和三角形
- 阻抗：600欧姆+10%
- 频率：1hz-1mhz正弦波  
- 振幅：0-3V在9V直流输入
- 失真：小于1% (1kHz)
- 平整度：+0.05db 1hz扩展方波
- 振幅：8v （空载）在9V直流输入
- 上升时间：小于50ns(1kHz)    
- 下降时间：小于30ns(1kHz)
- 对称性：小于5% (1kHz)
- 三角波振幅：0-3V在9V直流输入
- 线性度：小于1% （高达100kHz） 10ma

## 接口，旋钮，跳线开关

- 电源接口：DC 5.5*2.1mm，极性内正外负，供电电压9~12V
- 信号输出接口：
  - GND：接地
  - SQU：输出方波
  - SIN/TRI：输出正弦波或三角波
- 旋钮：
  - Amp(Amplitude)：调节正弦波和三角波幅度
  - Fine：细调频率
  - Coarse：粗调频率
- 跳线开关1：
  - Tri(Triangle)：选择三角波
  - Sin(Sine)：选择正弦波
- 跳线开关2：
  - 65k-1MHz
  - 3k-65kHz
  - 100-3kHz
  - 10-100Hz
  - 1-10Hz

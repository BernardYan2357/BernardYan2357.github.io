# 程序调试

## 常用的调试方法

1. **串口调试**：通过串口通信将调试信息打印到电脑屏幕。
2. **OLED调试**：通过将显示屏与STM32连接，显示调试信息。
3. **Keil调试**：使用Keil的调试功能，可以单步运行，设置断点，查看寄存器等。

## OLED调试

将OLED屏连接到STM32开发板，使用OLED显示屏来调试程序。

## Keil调试

点击魔术棒图标，点击`Debug`按钮，可以选择硬件仿真或电脑模拟仿真。

### 配置调试选项

1. `options for target`->`debug`->`debugger`：选择调试器，默认是ST-Link。
2. 选择`ST-Link Debugger`-硬件仿真，也可以选择`use simulator`-电脑模拟仿真。

### 窗口布局

- 上侧第一栏：
  - Peripherals：外设菜单栏，可以看到所有外设寄存器的状态。
- 上侧第三栏从左到右依次为：
  - 复位
  - 全速运行
  - 停止运行
  - 单步运行
  - 跳过当前行单步运行
  - 跳出当前函数单步运行
  - 跳到光标指定行单步运行
  - 显示黄色箭头：指示下一步运行的代码
  - 命令窗口
  - 反汇编窗口：查看汇编代码
  - 符号窗口：查看变量的值，局部变量可能不会显示
  
    在窗口中找到变量，右键单击，选择`Add Watch`，可以监视变量的变化。
  - 串口显示窗口
  - 逻辑分析仪窗口：显示时钟信号，可以查看时序波形

- 左侧寄存器一栏：显示寄存器组和状态标志位

### 注意事项

- 调试模式下不能修改代码

# 3D 打印

## 耗材

- **PLA**：玉米淀粉做的，熔点低，不怎么收缩，气味也小，是最容易上手的一种，打摆件、手办、模型很合适。缺点是脆、怕热，夏天放车里或者靠近暖气片容易变形，也不耐晒和耐潮。
- **PETG**：可以当成 PLA 的加强版，韧性比 PLA 好不少，没那么脆，耐温和耐化学性也更好，还能稍微弯一点。代价是容易拉丝，表面偏亮、偏"糊"，打印速度要放慢，调参比 PLA 麻烦。适合做功能件、卡扣、需要一定强度又不想折腾 ABS 的东西。
- **ABS**：老牌耗材，强度和耐温都不错，抗冲击，可以用丙酮抛光或者粘合。缺点是打印时收缩明显，容易翘边和开裂，最好有封闭腔体，气味也比较大。以前是功能件的默认选项，现在很多场合被 PETG 和 ASA 取代。
- **ASA**：相当于改良过的 ABS，耐候性特别好，抗紫外线和抗老化，户外用不会轻易变黄变脆。收缩和气味的问题比 ABS 小一些，但还是要封闭腔体和通风。户外零件、汽车上用的件选它。
- **TPU**：软的弹性材料，能拉伸、能回弹，做手机壳、减震垫、鞋垫、密封件这类需要柔性或者耐磨损的东西。打印难点在于它是软的，普通近端挤出机容易卡料，通常要直接驱动挤出机，速度也要慢下来。
- **尼龙（PA）**：强度、韧性、耐磨性都很好，有一定自润滑性，齿轮、铰链、受力结构件常拿它来做。问题是吸湿严重，打印前必须干燥，受潮了打出来会有气泡、强度大打折扣，另外也容易翘边。
- **PVA**：水溶性的，专门用来打双喷头的可溶支撑，打完泡水里就能化掉，适合复杂悬空结构。缺点是贵、吸潮快、保存要密封干燥。
- **HIPS**：可以用柠檬烯溶解，常和 ABS 搭配做可溶支撑；它本身性能一般，主要价值在支撑。

选材大致上：单纯看外观和好打，PLA 够用；要强度和韧性兼顾，PETG；要耐温、耐候、耐用，ASA 或尼龙；要软，TPU；要可溶支撑，PVA 或 HIPS

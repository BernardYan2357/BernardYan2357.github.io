# 机器视觉词典

## 图像特征描述

### 伪影（artifact）

- [常见的伪影 · Digital Video Concepts](https://wangwei1237.gitbook.io/digital_video_concepts/shi-pin-zhi-liang-du-liang/4_1_0_compressionlossartifactsandvisualquality/4_1_2_commonartifacts)
- 在图像生成领域，伪影也指模型生成出本不该存在的东西，比如模糊的斑块、奇怪的纹理，或一只手上多出来的手指

## 图像处理

### Padding

Padding，填充。

- 补零：用黑色（像素值为零）填补，容易产生伪影：在图像边缘制造亮度突变
- 镜像：顾名思义

# 视觉抓取算法

基于视觉的抓取算法：目的是给定一个包含物体的场景、一个机械手模型，算法以该场景的视觉信息为输入，计算出一个最优的抓取位姿，使机械手在该位姿下可以稳定地抓取物体

视觉抓取算法的分类：

- 物体：物体模型已知，物体模型未知
  - 数据法:首先根据物体模型生成大量的抓取位姿，并保存为数据库；当物体出现在场景中时，检测物体位姿；将数据库中与该物体对应的抓取位姿进行坐标变换，再经过碰撞检测筛选，获得最终的抓取位姿
  - 经验法:首先收集包含视觉信息与抓取标签对应的数据集，使用该数据集训练一个抓取检测算法(如神经网络)；在抓取时以实际场景的视觉信息为输入，即可输出抓取位姿，典型的算法有GGCNN，Anygrasp等
- 场景：
  - bin-picking：从多个物体堆叠的场景中依次抓取出物体，按照从上到下的顺序或无序抓取
  - 操作物体：首先检测物体的功能性部分(如水杯的手柄)，然后抓取功能性部分进行后续操作(如倒水)
  - hand-over：机器人与人类或其他机器人之间的物体交接
- 机械手：双指，多指，吸盘
- 视觉信息：RGB图像，深度图像&点云(两者可以相互转换)
  - RGB图像：可以预训练，但容易被光照、纹理等因素干扰
  - 深度图像&点云：可以感知物体形状，几乎无预训练模型，与深度相机精度相关
- 抓取位姿：平面抓取，6DOF抓取
  - 平面抓取：限制机械臂垂直抓取，即roll和pitch设为定值，抓取算法只预测$[x, y, z, yaw, w]$，其中$w$表示抓取宽度
  - 6DOF抓取：不限制机械臂抓取姿态，抓取算法需要预测完整的位姿信息$[x, y, z, roll, pitch, yaw, w]$

## 平面抓取

### 平面抓取检测数据集

[Cornell Grasp Dataset](https://www.kaggle.com/datasets/oneoneliu/cornell-grasp/data)
- 包含885张RGB图像，全部为单物体场景，在实验平台上随机摆放物体
- 由人工使用抓取矩形框标注
- 数据类型为：$[x, y, \theta, n, m]$，其中$(x, y)$为抓取中心点坐标，$\theta$为机械手相对于水平方向的旋转角度，$n$和$m$分别为机械手张开宽度和机械手夹爪的尺寸

缺点：
1. 由人工标注，标注的抓取框离散，不能覆盖所有可能的抓取位姿，且标注质量受主观因素影响（标注的位姿机器人可能不可达）
2. 没必要在数据集中用$m$表示机械手夹爪的尺寸，因为在实际应用中，机械手的尺寸是固定的，可以直接在标注时用碰撞检测考虑夹爪尺寸，并在算法中使用常数表示夹爪尺寸
3. 没有提供深度图

[Dex-Net 2.0](https://berkeleyautomation.github.io/dex-net/)
- 包含670万个抓取标签及图像块，全部为仿真环境下的单物体场景，使用仿真深度相机拍摄RGBD图像
- 使用力封闭原则在每个物体模型上采集数百个抓取位姿

### 基于深度学习的平面抓取算法

#### GG-CNN

- [Closing the Loop for Robotic Grasping: A Real-time, Generative Grasp Synthesis Approach](https://arxiv.org/abs/1804.05172)
- [GG-CNN复现](https://github.com/OneOneLiu/ggcnn_cornell_dataset)

- 基于生成对抗网络的抓取姿态估计方法，适用于实时抓取任务，由Cornell Grasping Dataset训练得到
- 模型输入：深度图像，输出：抓取姿态（位置和方向）

- 模型输入：RGB-D图像，输出：抓取姿态（位置和方向）

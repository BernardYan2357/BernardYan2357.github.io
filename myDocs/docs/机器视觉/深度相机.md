# 深度相机

深度相机（3D相机）按技术原理分类：

- 结构光（Structured Light）：采用特定波长的不可见的红外激光作为光源，它发射出来的光经过一定的编码投影在物体上，通过一定算法计算返回的编码图案的畸变来得到物体的位置和深度信息
	- 单目结构光：容易受光照的影响，在室外环境下，激光器发出的编码光斑容易太阳光淹没掉
	- 双目结构光：在室内环境下使用结构光测量深度信息，在室外光照导致结构光失效的情况下转为纯双目的方式，其抗环境干扰能力、可靠性更强
- 飞行时间（Time of Flight，ToF）：通过红外发射器发射调制过的光脉冲，遇到物体反射后，用接收器接收反射回来的光脉冲，并根据光脉冲的往返时间计算与物体之间的距离。这种调制方式对于时间的测量有极高的精度要求。在实际应用中，通常调制成脉冲波（正弦波），当遇到障碍物发生漫反射，再通过特制的CMOS传感器接收反射的正弦波，这时波形已经产生了相位偏移，通过相位偏移可以计算物体到深度相机的距离
	- 拍摄物体具有多个棱角时，会造成光线折射返回到摄像头，导致测量结果失真
	- 强烈的阳光也会导致镜头芯片快速饱和无法检测红外的真实性，导致失真
- 双目立体视觉（Stereo Vision）​：基于视差原理，利用成像设备从不同的位置获取被测物体的两幅图像，通过计算左右图像对应点间的位置偏差，来获取物体三维几何信息
	- 双目相机的优点：
		- 硬件要求低，成本也低。普通 CMOS 相机即可
		- 室内外都适用。只要光线合适，不要太昏暗
	- 双目相机的缺点：
		- 对环境光照非常敏感。光线变化导致图像偏差大，进而会导致图像匹配失败或精度低
		- 不适用单调缺乏纹理的场景。双目视觉根据视觉特征进行图像匹配，没有特征会导致匹配失败
		- 计算复杂度高。该方法是纯视觉的方法，对算法要求高，计算量较大
		- 基线限制了测量范围。测量范围和基线（两个摄像头间距）成正比，导致无法小型化

#### 传统像素匹配算法

| 算法分类                   | 算法    | 算法描述                                | 优点                     | 缺点               |
| ---------------------- | ----- | ----------------------------------- | ---------------------- | ---------------- |
| **局部法**：对像素周围小区域进行约束   | 区域匹配  | 在两幅图像给定区域内搜索中心点最大相关值或最小偏差值          | 直观，简单                  | 对噪声敏感，弱纹理区易造成误匹配 |
|                        | 特征匹配  | 寻找特征（点、线、边缘等）之间的相似度，而不是亮度本身         | 速度快，精度高，克服区域法对弱纹理区的敏感性 | 不适用缺少明显特征的环境     |
|                        | 相位匹配  | 对带通滤波信号的相位信息进行处理，寻找局部相位相等的对应点       | 可直接得到亚像素级精度，抑制高频噪声     | 奇异点不稳定           |
| **全局法**：对扫描线乃至整幅图像进行约束 | 动态规划  | 在左右图像对应的扫描线上寻找最小匹配代价路径              | 提高局部无纹理区匹配精度           | 视差图上易出现条纹瑕疵      |
|                        | 图割法   | 根据能量函数构造合适的图，求其最小割（最大流）             | 能有效去除条纹瑕疵              | 较动态规划算法的计算复杂度高   |
|                        | 置信度传播 | 用马尔科夫随机场（MRF）进行建模，求 MRF 最优解来获得最佳视差图 | 精度高                    | 计算复杂度高           |

#### Stereo foundation models

传统像素匹配算法对于缺乏视觉特征的场景（如天空、白墙、沙漠等）会出现匹配困难，导致匹配误差较大甚至匹配失败。那么我们可否使用神经网络进行像素匹配呢？

Stereo foundation models（双目立体视觉基础模型），指通过大规模、多样化数据训练，能够在不同场景中进行左右图像匹配、估计视差的通用深度学习模型。使用 Stereo foundation models，输入左右图像，能够输出**视差**

Stereo foundation models 按推理速度可以分为 Non Real-time 和 Real-time 两种，其中 [Fast-FoundationStereo](https://nvlabs.github.io/Fast-FoundationStereo/) 是 Real-time 分类中的 SOTA，it can run over 10× faster than FoundationStereo(Non Real-time) while closely matching its zero-shot accuracy!
